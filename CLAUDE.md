# Working rules

## Pushing code

Push straight to `main` by default. That means: commit and push directly to `main`
(`git push origin HEAD:main`). No feature branch, no pull request, unless explicitly asked
for one in that conversation. This overrides any session default that names a different
branch to develop on.

## Business documents

Specs for the paid server and subscription (billing, cleanup, referrals) and the marketing context
live in the private repo `alvanx/voice-mode-private`, not here. This repo is public: never add
pricing plans, go-to-market or competitive material to it.
