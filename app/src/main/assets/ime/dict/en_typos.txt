# Common English misspellings and the word that was meant, one per line:
#
#     <typo><TAB><correction>
#
# Read at runtime by TypoCatalog (ime/nlp/latin/TypoCatalog.kt). A typed word whose lowercase form is a
# typo here gets its correction offered first in the strip, and Space may swap it in when autocorrect is
# on. The typed capitalisation is carried over (Teh -> The, TEH -> THE). A correction may be more than one
# word (alot -> a lot). Lines starting with '#' and blank lines are ignored; typos are matched lowercased.
#
# An entry belongs here only when:
#  - the typo is not a word of the language in its own right. That rules out every confusion between
#    two real words (form/from, its/it's, lose/loose, then/than, wether/whether), which a list cannot
#    decide and which belongs to the context model, if anywhere;
#  - it is not an apostrophe restoration (dont, im, youre): those are handled by the contraction logic in
#    LatinLanguageProvider, from corpus evidence;
#  - every word of the correction is in en.json, written as en.json writes it.
#
# The typos must also be absent from en.json, because a word the dictionary knows is never corrected.
# tools/glide-dict/generate.py drops every typo listed here when it builds <lang>.json, so a regenerated
# dictionary stays clean; TypoListTest checks both rules against the shipped files.
#
# Source: curated by hand for this project from general knowledge of frequent misspellings, with each
# typo checked to be rejected by the Hunspell en_US, en_GB, en_CA and en_AU dictionaries. Not copied from
# any published list.
